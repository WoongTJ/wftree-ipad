# 워크플로우 트리 제작기 (아이패드판)

앱 본체만 올려 둔 공개 페이지다. 문서는 이 저장소에 두지 않는다. 편집한 트리는 쓰는 기기의 파일 앱과 브라우저 자동 저장에만 남는다.

- 주소: https://woongtj.github.io/wftree-ipad/
- 판 번호는 화면 위쪽에 `v1.2.4-ipad.N`처럼 작게 보인다. 새 판이 있으면 '새 판이 있습니다 · 새로고침'이 뜬다.
- 라이선스: MIT. 글꼴 Noto Sans KR은 SIL OFL(`fonts/OFL_NotoSansKR.txt`).

이 저장소에는 회사 자료, 비밀, 키, 실제 트리 파일을 넣지 않는다.
